# 📸 Flet Image Converter

Простой и мощный десктопный конвертер изображений, написанный на **Python** с использованием **Flet**. 
Утилита позволяет массово переводить фотографии из профессиональных RAW-форматов (`.nef`, `.cr2`, `.arw`) и мобильного формата Apple (`.heic`) в оптимизированные `.jpg`, `.png` или `.webp`.

## ✨ Ключевые возможности
*   🚀 **Поддержка RAW & HEIC**: Прямая конвертация файлов с камер Nikon, Canon, Sony и iPhone.
*   🎨 **Умная обработка прозрачности**: При сохранении PNG/WebP с альфа-каналом в JPG автоматически создается белая подложка (изображение не ломается).
*   ⚡ **Высокая скорость**: Оптимизированная пакетная обработка файлов без перегрузки оперативной памяти.
*   📦 **Современная сборка**: Конфигурация проекта полностью построена на базе актуального стандарта `pyproject.toml`.

## 🛠️ Технологический стек
*   **Язык**: Python 3.10+
*   **GUI Фреймворк**: Flet (Flutter для Python)
*   **Обработка графики**: Pillow, RawPy, Pillow-Heif

## 🚀 Быстрый старт и установка

### 1. Клонирование репозитория
```bash
git https://github.com/God-bo-coder/Convertag.git
cd Convertag
```

### 2. Установка зависимостей
Благодаря поддержке `pyproject.toml`, все библиотеки устанавливаются одной стандартной командой pip:
```bash
pip install .
```

### 3. Запуск приложения
```bash
python main.py
```
